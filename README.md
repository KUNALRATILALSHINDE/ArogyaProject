🌿 Arogya Health Website
Overview
Arogya Health is a wellness platform offering Yoga info, Prakriti tests, Brain games, and a Chatbot for guidance. 🧘‍♂️🧠💬

Features
🧘 Yoga Info: Learn poses & benefits.
🏥 Prakriti Tests: Know your body type.
🎮 Brain Games: Boost mental agility.
🤖 Chatbot: Get health & wellness tips.

Tech Stack
💻 Frontend: HTML,CSS,JS
🛠 Backend: Node.js, Express.js
🗄 Database: MongoDB
🤖 AI: ML models for chatbot & recommendations

Setup 🚀
Clone the repo:
git clone https://github.com/yourusername/arogya-health.git
cd arogya-health

Install dependencies:
npm install
Start the server:
npm start
Open http://localhost:3000 in your browser.
